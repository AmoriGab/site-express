# Catálogo Express

Modelo de site-catálogo estático (produtos, carrinho e pedido pelo WhatsApp) (HTML + CSS + JavaScript puro), 4 páginas, tema claro/escuro, carrossel, WhatsApp flutuante. Sem build, sem banco de dados, sem dependências obrigatórias.

- **Personalizar:** edite os 5 arquivos de `config/` (produtos em `config/products.js`) e troque as imagens em `assets/images/`. Veja `03-DOCUMENTACAO/01-MANUAL-DE-PERSONALIZACAO.md`.
- **Publicar:** coloque o conteúdo desta pasta (com `index.html` na raiz) na pasta pública da hospedagem. Veja `03-DOCUMENTACAO/02-MANUAL-DE-PUBLICACAO.md`.
- **Importante:** extraia o ZIP antes de abrir. O site não funciona aberto de dentro do ZIP nem com o `index.html` copiado sozinho: ele precisa das pastas `assets` e `config` ao lado.
- **Testar localmente:** abra `index.html` no navegador (duplo clique).

Documentação completa em `03-DOCUMENTACAO/`.
